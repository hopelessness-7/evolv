# 0008. PHP 8.5 в Docker / PHP 8.5 in Docker

- **Status:** Accepted
- **Date:** 2026-06-24

---

## Русский

### Контекст

Проект использует актуальный PHP. Образ Sail 8.4 устарел относительно целевой версии.

### Решение

Кастомный образ `docker/8.5/` на Ubuntu 24.04 + ondrej/php 8.5. Composer копируется из официального образа `composer:2` (без PHP-installer в RUN — избегаем SSL-сбоев при сборке).

`composer.json`: `"php": "^8.5"`.

### Последствия

**Плюсы:** последние фичи PHP 8.5; стабильная сборка Docker.

**Минусы:** пакеты без поддержки 8.5 могут потребовать форков (маловероятно для Laravel 13).

---

## English

### Decision

Custom `docker/8.5/` image with PHP 8.5. Composer via multi-stage copy from `composer:2`.

### Consequences

**Pros:** latest PHP; reliable Docker builds.

**Cons:** rare package incompatibility risk.
